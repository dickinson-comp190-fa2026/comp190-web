# Git Alias Examples

from my `.bash_profile`:

```bash
alias gs='git status'
alias ga='git add --all'
alias gc='git commit'
alias gcm="git commit -m'minor update'"
alias gl='git log'
alias glg='git log --graph --pretty=oneline --abbrev-commit'
alias gp='git push'
alias gpl='git pull'
```

**very cool and useful!!**
