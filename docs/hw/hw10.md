# Homework assignment HW10

## Homework log

A homework log is not required for this assignment.

## Objectives

Complete chapter 3 of the GitKit book ("Working Locally and Upstreaming Changes").

## Likely quiz questions

Give Git commands that perform the following actions:
* Stage changed files to be committed to the repo.
* Commit staged files with a message.
* Push a feature branch to your origin.
* Display recent commits made to the active branch.
* Change the active branch.
* Check the current state of your local repo.
