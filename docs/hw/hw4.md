## Objectives

This assignment  

Minimal knowledge and experience to acquire include the following:
* usage of `env` to view environment variables, and `echo` to print the value of a variable, e.g. `echo $PATH`
* updating the value of an environment variable, e.g. `export PATH=$PATH:/home/username/bin`
* use of `sudo` to run commands with elevated privileges
* use of `groups` to view the groups that a user belongs to, e.g. `groups username`
* use of `sudo apt update` to update the list of available packages
* use of `apt` to install software packages, e.g. `sudo apt install cowsay`
* Install Java (`default-jdk`), then create, compile, and run a hello world program. 
* use of `apt search` to search for available packages, e.g. `apt search cowsay`
