## Objectives

This assignment covers the use of the Unix tools `find` and `grep`, and the utility `ripgrep` (a faster and more developer-friendly version of `grep`). You will learn how to use these tools to search for files and text in files, and how to use _regular expressions_ to perform more complex searches.

Minimal knowledge and experience to acquire include the following:
* Use the `find` command to search for files matching a given name or pattern e.g. `find . -name "*.txt"` to find all text files in the current directory and its subdirectories.
* Use the `find` command to search for directories matching a given name or pattern e.g. `find . -type d -name "src"` to find all directories named `src` in the current directory and its subdirectories.
* Use the `grep` command to search for text in files e.g. `grep "TODO" *.py` to find all occurrences of the string "TODO" in Python files in the current directory.
* Use the `ripgrep` command to search for text in files e.g. `rg "TODO" -t py` to find all occurrences of the string "TODO" in Python files in the current directory and subdirectories recursively.
* Use regular expressions with `grep` and `ripgrep` to perform more complex searches e.g. `grep -E "TODO|FIXME" *.py` to find all occurrences of the strings "TODO" or "FIXME" in Python files in the current directory.
