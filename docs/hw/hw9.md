## Homework log

A homework log is not required for this assignment.

## Objectives

Complete chapter 2 of the GitKit book ("Communities and Collaboration"). The book is available on our [Readings](../readings/) page. The exercises require you to use a particular fork of the FarmData2 project, which is also available on the Readings page.

## Likely quiz questions

Give Git commands that perform the following actions:

* Display Git settings.
* List your remote repos.
* Create a copy of the origin repository in your development environment.
