## Objectives

The main objective for this assignment is to learn usage of a wider range of command line utilities in the Linux environment from HW1. At a minimum this should include (some of these are repeats from the previous assignment):
* absolute and relative paths; `whomai`; `pwd`; how to represent the absolute and relative versions of the path to your home directory; the root directory; 
* `cd`, `cd ~`; `cd /`; `cd ..`; 
* `ls`, `ls -a`, `ls -l`, `ls -al`, `ls -lh`, `ls -R`; 
* `mkdir`, `mkdir -p`; `rmdir`; `rm`, `rm -r` _careful!_; 
* `cp`, `cp -r`; `mv`; 
* the use of wildcards in file names; 
* `cat`; `man`; `head`; 
* short form and long form command line options
* hidden files
* the `nano` text editor, including how to create a new file, edit an existing file, save a file, and exit the editor
